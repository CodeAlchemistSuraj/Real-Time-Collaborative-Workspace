## 📦 Installation

### Prerequisites
- JDK 21+
- Maven/Gradle
- Docker (optional)

### Build Instructions
```bash
# Clone the repository
git clone https://github.com/CodeAlchemistSuraj/Real-Time-Collaborative-Workspace.git

# Navigate to project directory
cd Real-Time-Collaborative-Workspace

# Build the project
./mvnw clean install

# Run the application
java -jar target/Real-Time-Collaborative-Workspace.jar
```
